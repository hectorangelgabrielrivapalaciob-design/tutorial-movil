# Tutorial Desarrollo Móvil – Sitio Web Responsivo

Sitio web tutorial educativo sobre temas de desarrollo de aplicaciones móviles.

## Estructura de archivos

```
tutorial-movil/
├── index.html          # Página principal (todo el contenido)
├── css/
│   └── styles.css      # Estilos cyberpunk azul/blanco + responsivo
├── js/
│   └── main.js         # Navegación, HUD, fondo matrix
└── README.md           # Este archivo
```

## Temas incluidos

1. **Control de versiones** – Definición, tipos (Git, SVN, Mercurial), ventajas/desventajas, funcionamiento, ejemplos y fuentes.
2. **Persistencia y acceso a datos** – Archivos, SQLite/Room, servicios web, autenticación, ORM.
3. **Gestión de sensores** – Tipos, proceso de habilitación y procesamiento.
4. **Uso de recursos multimedia** – Imágenes, audio, video, animaciones, ubicación en el proyecto.
5. **Servicios y notificaciones** – Background tasks, notificaciones, FCM, servicios en la nube.
6. **Librerías y toolkits** – Diferencia library vs toolkit, Jetpack, Flutter, React Native, etc.
7. **Depuración y seguridad** – Herramientas de Android Studio y Xcode, buenas prácticas.

## Cómo abrir

1. Descomprime el ZIP.
2. Abre `index.html` en cualquier navegador moderno (Chrome, Firefox, Edge, Safari).
3. No necesita servidor: funciona con doble clic.

## Diseño

- Estilo **cyberpunk** con tonos azules y blanco sobre fondo oscuro.
- Layout de 3 columnas en escritorio (navegación + contenido + panel lateral).
- Totalmente **responsivo** (móvil, tablet, desktop).
- Fondo tipo “matrix” sutil.
- Navegación por secciones sin recargar la página.
